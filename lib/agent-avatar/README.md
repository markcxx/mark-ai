# MarkAI agent avatar engine

The framework-independent SVG morphing engine under `bloub/` is vendored from
[jeremy-prt/bloub](https://github.com/jeremy-prt/bloub), version 0.1.1. It is
used by MarkAI's React chat avatar without the original Vue editor, capture, or
video export layers.

The upstream code is MIT licensed. See `bloub/LICENSE`.
