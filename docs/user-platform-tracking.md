# 用户平台使用记录

管理后台的用户列表显示使用过的平台，并支持按 Web、Android、未知平台筛选。用户详情的“安全 → 使用平台”展示首次记录、最近使用时间和最近一次 Android 应用版本。手机浏览器属于 Web。

## 部署

1. 部署前执行 `npm run db:migrate`，应用 `0012_wet_zarda.sql`。该迁移新增 `user_platforms`，并从仍保留的登录会话回填可识别的 Web / 未知记录。不重建已删除的历史会话。
2. 部署服务端和管理后台。
3. 构建并发布包含 `client_identity.dart` 的新版 Android APK。旧版不会发送明确的平台和版本信息，不能可靠地补推它们的 Android 使用记录。

## 记录规则

- 只对已认证、未封禁用户的受保护页面/API访问记录；匿名访问和本地模式不写入。
- Android 请求携带 `X-MarkAI-Platform: android` 和 `X-MarkAI-App-Version`，版本取自已安装包的原生信息。Web 从可识别的浏览器 User-Agent 判断，其他来源保留未知。
- 用户身份仅取自服务端认证会话。平台和版本是客户端自报的展示信息，不作为权限、安全风控或计费依据。
- 每个用户每个平台一条记录，以用户为外键。退出登录、撤销或清理登录会话不会删除记录；删除用户时级联删除。
- 相同平台/版本的活跃时间约每 5 分钟更新，版本变化立即记录。记录的是请求活动，不代表在线状态。多设备使用不同版本时显示最近观察到的版本，不代表该用户所有设备都已升级。
- 写入失败不阻断业务。数据库迁移必须先完成，后台查询需要新表。
- 不采集设备唯一标识，也不额外存储 IP 或完整 User-Agent。
