# MarkAI Android 1.0.12

本次更新带来更灵活的思考模式控制，并优化附件发送和设置体验。

## 新增

- 新增深度思考开关：使用支持切换思考模式的模型时，可在输入框中直接开启或关闭，按需选择回答方式。
- 新增底部附件面板：点击发送按钮左侧的加号，即可选择拍照、相册或文件。

## 优化

- 待发送图片以正方形缩略图展示在输入框顶部，方便查看和移除。
- 调整发送按钮大小与工具栏布局，改善小屏手机上的操作体验。
- 收紧设置分类和选项间距，让常用设置更集中、浏览更高效。
- 统一思考开关与消息思考区的图标，让状态更容易识别。

## 修复

- 修复待发送文件居中显示的问题，附件统一靠左排列。
- 改善附件面板与键盘切换、返回键关闭面板时的交互。

思考模式开关仅在当前模型及接入服务支持时显示；可用能力取决于模型配置。
