- Flutter Android 工程、地址配置、能力探测、云模式游客草稿。
- 邮箱密码登录、Cookie 安全保存、退出登录；API 401 与网页重定向分离。
- 模型 provider/id 配对、搜索与选择偏好写回。

- 明暗主题、字体、Logo/模型 SVG、主要操作的 Lucide 图标。
- 部分通用设置、恢复副本读取与导出。

## 游客与登录界面对照修正（2026-09-09）

- 用户明确选择继续使用 Flutter 原生组件，不采用 WebView 承载应用 UI。
- 游客页独立对应 `components/guest/GuestChatApp.tsx`：顶部品牌、主题与登录入口，居中的欢迎区和输入框；不显示已登录侧栏或会话菜单。
- 登录从弹窗改为完整页面，对应 `app/(auth)/layout.tsx` 和 `login/page.tsx`，恢复外框、引导区、第三方入口、分隔线、邮箱/密码标签和底部注册入口。
- 清除 Material 默认字距与按钮额外占位；本地 SVG 使用 Web 端相同 Lucide 路径。
- 助手头像由原有 BotEngine 导出 60 FPS 几何数据，在 Flutter Canvas 中绘制。包括 idle 与 7 个状态片段；这不是完整引擎的 Dart 移植，随机表情、指针跟随、连续点击反应仍未完全一致。
- 增加原生找回密码表单、注册模式查询及邮箱验证码/等候名单基础流程；邀请、注册后的资料引导与全部注册细节尚未完成。
- Google/GitHub 入口目前明确提示原生授权尚未接通，**不能视为已经实现第三方登录**。
- 游客主题只写本地存储，不请求受保护的设置 API。登录返回后保留游客草稿。

此前验证使用了 390×844 网页截图、同尺寸且加载真实字体的 Flutter 测试渲染，以及包含系统安全区的 Pixel 7 模拟器集成测试截图。历史图片已清理；`mobile/qa/` 仅作为 Git 忽略的本地生成目录，需重新运行截图测试获取当前结果。测试截图不证明真实账户认证已经完成。
