# Android 接口与故障核对（2026-09-09）

本次核对不使用真实用户密码，不把模拟登录或接口路径存在当作真实账户联调成功。

## 已复现并修复

1. 邮箱登录：模拟器用 `10.0.2.2:3000` 访问宿主机，客户端原先也把它作为 Origin；现有 Better Auth 的 APP_URL 是 `localhost:3000`。原请求返回 `403 INVALID_ORIGIN`，尚未校验密码。调试客户端现在把这个 HTTP 回环传输别名对应到 localhost Origin；正式 HTTPS 地址保留原 Origin，服务端校验没有关闭。相同的无效测试凭据经正确 Origin 返回 `401 INVALID_EMAIL_OR_PASSWORD`。
2. 偶发缩小：头像的多色环绕渐变没有提供 colorStops，触发绘制异常；CustomPainter 未保护自身缩放/位移，污染后续绘制。现已提供完整渐变位置，并用 save/try/finally/restoreToCount 隔离绘制。测试覆盖到达动画、空闲和后续动画的画布矩阵、裁剪区域及保存栈。

## UI 等价的瓶颈

Flutter 原生并非无法实现；当前工程尚未完成逐组件、逐状态的完整移植。网页动态头像的几何片段复用不等于完整交互引擎移植，默认 Material 行为也不等于网页交互。静态几何对照和关闭动画的截图测试没有覆盖真实动画异常，模拟 API 没有覆盖真实服务的 Origin/Cookie 要求。本次添加的测试专门弥补这两个已发现的盲点，并不构成全应用验收。
