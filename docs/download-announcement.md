# 下载页与公告

- `/download` 为公开页面，无需登录。聊天账号菜单和游客页提供「下载 App」入口。
- Android 当前版本、大小、更新说明与双渠道链接来自 `/api/public/android-update`，该接口读取 GitHub Releases；没有硬编码某个版本的 APK。iOS 仅展示「敬请期待」。
- 下载服务失败时显示重试和 GitHub Releases 入口，不生成假的下载链接。
- 管理端 → 站点公告：支持显示开关、用户关闭权限、跳转按钮开关、按钮文字和跳转地址。填写纯文字（最多 1000 字）后点击「保存公告设置」。关闭显示会保留内容；每次保存生成新的公告修订号。
- 公告采用参考项目的顶部流动彩色渐变，横跨整个聊天应用宽度（包括导航栏），聊天工作区和移动端抽屉均位于公告下方。后台预览与前台复用同一个组件。
- 聊天页、游客页和下载页显示公告；每分钟以及重新聚焦时刷新。用户关闭公告后，通过 localStorage 在当前浏览器持久记住公告修订号，刷新、重开浏览器及同源其他标签页均不再显示同一修订（清除网站数据后失效，不跨设备同步）；公告重新发布后可再次显示。长公告在提示条内滚动，不挤占整个对话区。
- 管理 API 复用管理员授权，跨域写入被拒绝；保存公告和操作审计一起写入数据库。公告以文字渲染，HTML 不会执行。
- 迁移 `0010_windy_omega_sentinel.sql` 创建公告表；`0011_lively_wiccan.sql` 增加显示、关闭权限和跳转配置。部署前执行 `pnpm db:migrate`。当前配置的数据库已完成两项迁移。

Android 启动更新提醒的修复需安装后续版本才能生效；已分发的 1.0.3 行为不会被网页部署改变。
