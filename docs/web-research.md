# 联网阅读与图片展示

启用聊天输入框的联网开关后，OpenAI 兼容、Anthropic 和原生 Gemini 共用同一组工具与来源注册表。模型根据任务选择工具；简单事实可以仅凭充分的搜索证据回答，指定文章的总结和细节核验则应读取正文。

## 工具链

| 工具           | 用途                                         | 主要输出                                  |
| -------------- | -------------------------------------------- | ----------------------------------------- |
| `web_search`   | 定位网页，按需请求配图候选                   | 搜索摘要、引用编号、图片 ID               |
| `read_webpage` | 阅读用户提供、搜索返回或已读页面链接中的 URL | 带行号的正文、`page.nextLine`、图片、链接 |
| `find_in_page` | 在同一页面查找字面词组，定位长文细节         | 匹配行号和相邻正文；无匹配时明确返回      |
| `show_images`  | 从已检索候选中选择 1–6 张图片                | 可放大、带来源链接的持久化图集            |

网页阅读沿用 Firecrawl → Tavily Extract → 直接请求/Jina Reader 的回退流程；提取 Markdown 和 HTML 中的正文图片、懒加载地址与页面链接。搜索不会额外生成供应商答案，模型可区分摘要和正文证据。网页原文、图片标题和说明作为不可信资料处理，不作为指令。

图片通过服务端登记的 ID 选择，模型不能通过 `show_images` 自行填写 URL。指定页面的配图应从该页面读取。仅有图片标题/说明不代表模型已视觉检查图片，此功能没有新增视觉识别工具。抓取可能只返回页面的部分图片，因此模型应说明本次提取范围；图集渲染后，正文应避免重复输出同一图片的 Markdown。

## 状态与边界

- 每轮最多读取 6 个不同页面、执行 16 次联网调用；普通联网任务最多 8 轮工具循环，随后请求最终回答。Word 工作流保留其 32 轮额度。
- 页面在本次生成中缓存；内部正文最多 240,000 字符。每次读取默认 80 行，最多 160 行、12,000 字符，长行以 240 字符拆分。模型可通过 `start_line` 续读；更短上下文会进一步压缩工具结果并保留定位提示。
- 页内查找是大小写不敏感的字面匹配，最多返回 12 个匹配行和邻近内容。未抓取到的内容、站点登录墙、验证码和纯浏览器交互不属于可检索正文。
- 保留公网 URL/DNS 与跳转检查，拒绝内网、非 HTTP(S) 和含账号密码的页面 URL。图片候选也会过滤明显的私有地址、图标和小图。未增加通用服务端图片代理。
- 浏览器/Android 直接加载公网原图，不转发 MarkAI API 的认证头。网页可能禁止外链或删除原图，此时显示失败提示并保留来源入口。公网域名的后续 DNS 变化和第三方重定向仍受外部网站影响，这不是完整的隔离浏览器。
- `tool` 消息片段新增 `callId`、`images`、`links`、`page` 和 `contentKind`，图集使用 `show_images` 工具片段保存。无需数据库迁移。相同 URL 的多次读取通过调用 ID 区分；中止时未完成工具转为错误状态。
- 后续对话通过有大小上限的 `webContext` 携带已展示图片和来源，支持“再展示第二张图”等追问。上下文预算计入这部分元数据；原始网页正文不会整篇重复注入后续轮次。
- 图片 URL 直接持久化，当前不提供图片离线副本或版权许可判断。网页图片与 AI 生成图片使用不同片段。

## 验证

建议在正常聊天中开启联网并测试：

1. 指定 URL：“阅读 https://www.dpm.org.cn/explore/building/236465.html ，核实太和殿走兽的数量，给出原文依据，展示该页面两张配图。”应直接读页，按需查找，显示真实图片与来源。
2. 未给 URL：“找故宫博物院太和殿官方介绍，核对建筑信息并配图。”应搜索定位，再阅读相关官方页面。
3. 长文细节：“在这篇长文中找到某项限制并给出上下文。”应读取或查找目标段落，不把缺失的摘要当成全文。
4. 停止生成、刷新会话，再追问“第二张图的来源是什么”。已完成图集应保留，未完成工具不得一直显示加载。
5. 简单事实、无配图需求的回答应避免无意义地逐页读取或展示不相关图片。

自动化覆盖提取与 URL 过滤、长页面末尾证据、分页缓存、候选 ID 校验、跨轮上下文、中止状态、三种模型协议和 Web/Android 渲染契约。实际工具选择仍依赖所用模型的工具调用能力，不能通过一次成功的工具测试保证所有模型的行为。

运行 `npm test`、`npm run lint`、`npx tsc --noEmit --incremental false`；Android 运行 `cd mobile && flutter analyze && flutter test`。共享检出目录运行开发服务器时不要同时执行生产构建。
