# 会话只读预览与分享

- 会话顶部「分享与导出 → 分享链接」创建当前已保存消息的快照。
- 有效期为 1 小时、1 天、7 天、30 天；每个会话保留一个链接。重新生成会替换快照和 token，撤销立即禁止后续访问。
- 快照包含当前选中的答案、思考、译文和附件引用，不包含其他答案版本。后续消息不会同步到快照。
- `/share/[token]` 无需登录，只呈现会话。管理端和分享页复用 `ReadonlyConversation` / `MessageItem`；不提供编辑、删除消息、重新生成等聊天操作。
- 文件通过 `/api/public/shares/[token]/files/[fileId]` 读取，每次验证期限、快照引用和文件所属用户，不公开对象存储直链。源文件被删除后无法继续预览。删除源会话或账户会级联删除分享。
- 分享页面禁止索引、缓存和传递 Referer。到期页面刷新不可读，已打开的页面在到期时移除内容；已经查看或下载的内容无法收回。

## 数据库

云端发布前执行 `npm run db:migrate`（需提供 `DATABASE_URL`），应用 `0009_wonderful_ultimatum.sql`，新增 `conversation_shares` 表。未增加环境变量。本地 SQLite 模式自动建表。

## 验证

分享存储、权限、文件访问和公开路由测试位于 `lib/chat/share-*.test.ts` 及对应 API 路由目录。验证覆盖期限、撤销、替换、会话删除级联、跨用户拒绝、文件越界和公开/受保护路由隔离。
